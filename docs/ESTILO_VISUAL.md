# Estilo visual

## Dirección elegida

La app sigue una línea:

```text
Soft Luxury Beauty
```

Eso significa:

- elegante
- suave
- femenina
- moderna
- calmada
- premium sin exceso
- clara para trabajar rápido

No significa:

- rosa chillón
- decoración vacía
- panel recargado
- estética infantil
- pérdida de contraste

## Paleta

Base:

- blanco roto
- crema suave
- beige cálido muy ligero

Acentos:

- rosa empolvado
- malva suave
- ciruela suave
- nude rosado

Apoyo:

- topo cálido
- gris rosado
- dorado/cobre muy sutil solo como matiz

## Reglas de interfaz

1. La marca debe sentirse en cabeceras, botones clave, superficies y foco visual.
2. La navegación y las acciones importantes deben seguir leyéndose de un vistazo.
3. Los degradados se usan solo en zonas de jerarquía:
   - cabeceras
   - botones principales
   - algunos bloques destacados
4. Las tablas y formularios deben seguir siendo sobrios.
5. Los estados visuales deben distinguirse bien, pero con tonos refinados y no con colores agresivos.

## Tipografía

- Sans para lectura y operación diaria.
- Serif elegante solo para titulares y títulos principales.

Así se gana identidad de marca sin perjudicar la velocidad de lectura.

## Componentes clave

### Navegación

- contenedor claro y pulido
- estado activo más visible
- sensación de marca sin parecer un menú corporativo genérico

### Botones

- principal: degradado de marca
- secundario: claro, limpio y sobrio
- éxito / advertencia / cancelación: diferenciados pero refinados

### Tarjetas y paneles

- superficies claras
- borde suave
- sombra contenida
- pequeño acento superior de marca en bloques principales

### Formularios

- fondos limpios
- foco visual suave
- labels claras
- sensación menos “backend” y más “herramienta cuidada”

## Criterio para futuras iteraciones

Si hay duda entre:

- más decorativo
- más usable

se prioriza siempre:

```text
más usable
```

La marca debe acompañar el trabajo, no estorbarlo.
