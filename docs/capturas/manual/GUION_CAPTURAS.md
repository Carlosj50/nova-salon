# Guion de capturas para la guía visual

Este documento ayuda a sacar las capturas con una línea coherente.

## Criterio general

Cada captura debe cumplir cuatro cosas:

1. enseñar una tarea real
2. evitar ruido visual innecesario
3. verse creíble como uso de salón
4. dejar claro dónde mirar

## Preparación del entorno

Antes de hacer capturas:

- usa el nombre real o comercial del salón
- deja el logo ya configurado
- crea varias clientas de ejemplo
- crea citas repartidas en distintos horarios
- deja al menos una pendiente, una confirmada y una completada
- evita pantallas completamente vacías salvo que quieras enseñar un estado vacío a propósito

## Formato recomendado

- una pantalla por captura
- sin scroll grande
- sin barras del navegador si no aportan
- sin fondos o ventanas ajenas a la app
- resolución limpia y consistente

## Orden recomendado

### 01-acceso-panel.png

Debe mostrar:

- logo
- nombre del negocio
- formulario de acceso

Evita:

- mensajes de error
- campos mal rellenados

### 02-agenda-lista.png

Debe mostrar:

- resumen del día
- lista con varias citas
- una o dos acciones visibles

Evita:

- una agenda demasiado vacía
- demasiadas filas si vuelve la lectura confusa

### 03-agenda-visual.png

Debe mostrar:

- varias citas distribuidas por horas
- algún hueco visible

Evita:

- un planning completamente vacío

### 04-nueva-cita.png

Debe mostrar:

- buscador de clienta
- servicio
- fecha y hora

Idealmente:

- una clienta ya seleccionada

### 05-ficha-clienta.png

Debe mostrar:

- datos básicos
- historial
- botones de nueva cita o repetir

### 06-repetir-cita.png

Debe mostrar:

- formulario con clienta y servicio ya cargados
- fecha sugerida visible
- atajos de fecha visibles si encajan

### 07-reprogramar-rapido.png

Debe mostrar:

- una fila de agenda con atajos de reprogramación

### 08-config-negocio.png

Debe mostrar:

- nombre
- logo
- teléfono
- bloque de identidad del negocio

### 09-config-usuarios.png

Debe mostrar:

- lista simple de usuarios
- rol
- estado activo

### 10-chat-demo.png

Debe mostrar:

- cabecera del negocio
- mensaje inicial del chat
- botones cortos o una conversación breve

## Datos que conviene usar

Quedan mejor nombres y datos de este tipo:

- Ana Martín
- Lucía Romero
- Marta Gil
- 600 123 123
- 611 234 234

Servicios creíbles:

- Corte mujer
- Mechas
- Manicura semipermanente
- Color raíz

## Datos que conviene evitar

- `Cliente prueba`
- `Test 01`
- `123456789`
- textos incompletos
- nombres duplicados sin sentido

## Consejo final

Si una captura no se entiende en tres segundos, conviene repetirla.
