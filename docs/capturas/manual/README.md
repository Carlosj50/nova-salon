# Capturas para la guía visual

Esta carpeta guarda las capturas usadas en la guía visual de uso.

La guía principal está en:

- [docs/GUIA_VISUAL_USO.md](/mnt/h/servicio_ia_negocios/docs/GUIA_VISUAL_USO.md)

Y el orden recomendado para sacar las capturas está en:

- [docs/capturas/manual/GUION_CAPTURAS.md](/mnt/h/servicio_ia_negocios/docs/capturas/manual/GUION_CAPTURAS.md)

Conviene mantener nombres cortos y estables:

```text
01-acceso-panel.png
02-agenda-lista.png
03-agenda-visual.png
04-nueva-cita.png
05-ficha-clienta.png
06-repetir-cita.png
07-reprogramar-rapido.png
08-config-negocio.png
09-config-usuarios.png
10-chat-demo.png
```

Regla práctica:

- una pantalla por captura
- sin scroll excesivo
- mostrando una tarea real
- con datos de ejemplo limpios

Si una captura cambia, intenta conservar el nombre para no romper la guía.
